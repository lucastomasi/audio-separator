# Coherent Linux/CPU dependency set for the Cursor Cloud Agent environment.
#
# The app targets macOS (see requirements-macos.txt), which is left untouched.
# That file cannot be installed as-is by a modern resolver because a few of its
# pins are mutually exclusive / unbuildable on Linux + Python 3.12:
#   - gradio==6.20.0 needs huggingface-hub>=1.2.0, but transformers==4.46.3
#     needs huggingface-hub<1.0 (hard conflict).
#   - infer-rvc-python==1.3.1 pins torchcrepe==0.0.20 / soxr==1.1.0 /
#     pyworld==0.3.4, which lack clean cp312 wheels.
#
# This file installs the coherent, importable subset that every committed module
# actually uses, plus the torch base and the Gradio web framework the app UI is
# built on. torch/torchaudio are installed from the CPU index in install.sh.
numpy<2
soundfile
scipy
picklescan
yt-dlp
onnxruntime
pedalboard
tqdm
gradio
